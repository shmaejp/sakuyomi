# スマホ側は PWA とし、ネイティブアプリや LINE にはしない

n1 の利用者は開発者の家族だけであり、アプリストアの審査と配布の手間に見合わないため、スマホ側は PWA（Vite + React の SPA）で作る。LINE は 40〜60 代になじみがあり、インストールも不要だが、送られた写真・音声から位置が取れず（位置からの圃場の推定ができない）、「記録する」と「聞く」の 2 つの入口や訂正の画面も LIFF で作り込むことになるため採らない。ネイティブアプリは、圏外で貯めた記録をバックグラウンドで再送できる点で優れるが、配布の手間がかかる。PWA の弱点（iPhone では、アプリを開くまで再送されない）の実害は n1 で計測する。他の農場に広げる段階で、ネイティブアプリか LINE を見直す。
