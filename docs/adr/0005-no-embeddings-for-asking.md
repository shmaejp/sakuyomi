# 問いかけに埋め込みを使わず、絞り込んだ記録を Claude にまるごと渡す

問いかけに答えるとき、一般的な作り方である埋め込み（ベクトル）による意味検索は使わない。代わりに、問いかけから圃場・作目・時期を読み取って記録を絞り込み、絞った記録の構造化結果をそのまま Claude に渡して答えさせる。1 つの農場の記録は年に千件程度であり、Claude は 100 万トークンの文脈を扱えるので、作目 1 つ分の数年分の記録なら、まるごと渡せる。この方式なら、埋め込み用の外部サービスもベクトル索引もいらず、「もとになった記録を示し、記録にないことは答えない」も守りやすい。記録が増えて渡しきれなくなったら、そのときに埋め込みによる検索を足す。
