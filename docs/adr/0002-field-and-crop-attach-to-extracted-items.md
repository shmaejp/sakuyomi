# 圃場・作目は記録ではなく、観察・判断・作業に結びつける

畑での話は「1番と2番ハウスのトマトに消毒した」のように、ひと言で複数の圃場や作目に及ぶことが多い。そこで、圃場・作目は記録そのものではなく、記録から取り出した観察・判断・作業のそれぞれに結びつける。1件の記録が複数の圃場・作目にまたがってもよく、観察・判断・作業の1つが複数の圃場・作目に結びついてもよい（上の例は、1番と2番の両方に結びつく1つの作業になる）。圃場ごとに分けて取り出すと、同じ根拠を持つ1つの判断が割れ、要約が冗長になり、訂正も複数か所で必要になるため、分けない。「その圃場の記録」とは、その圃場についての観察・判断・作業を含む記録のことである。記録に圃場・作目を1つずつ持たせる方式は単純だが、またがる話を分けて録り直させることになり、入力の負荷が増えるため採らない。
