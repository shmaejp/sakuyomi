# 構造化結果を版として残し、訂正済みの記録は作り直さない

ADR 0001 で、構造化結果は新しい AI でいつでも作り直せる派生物とした。しかし、作り直しで上書きすると、家族が要約の画面で直した訂正が黙って消えてしまう。そこで、構造化結果は記録ごとに版として残し、版を作ったのが AI か人（訂正）かを持たせる。訂正するたびに新しい版を作り、作り直しは、まだ訂正されていない記録にだけ行う。人の訂正は AI より確かなので、訂正済みの記録は人の版を使い続ける。訂正済みの版は、そのまま構造化の質を測る評価用の正解データになる。作り直しのときに過去の訂正を AI に渡して反映させる案は、結果が予測しにくくなるため採らない。
